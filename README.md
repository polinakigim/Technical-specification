# Technical Specification: ЭлектроСеть API
## Описание проекта
Это REST API для управления сетью электросетей и их взаимосвязями поставщиков и покупателей. Система позволяет создавать и хранить данные о сетях, их продуктах, а также отслеживать задолженности перед поставщиками.

Функционал
CRUD (создание, чтение, обновление, удаление) для моделей Network и Product.

- Поддержка вложенной структуры поставщиков (Network может ссылаться на другого Network как на поставщика).
- Автоматическое вычисление уровня сети в иерархии поставок.
- Отслеживание задолженности перед поставщиками.
- Защита поля debt_to_supplier: его можно задавать только при создании, нельзя редактировать после.
- Аутентификация и авторизация через Django REST Framework.
- Административная панель Django для удобного управления моделями.

## Установка и запуск
### Шаги установки
Клонируйте репозиторий:

```bash
git clone https://github.com/your_username/your_project.git
cd your_project
```
Создайте и активируйте виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

Установите зависимости:

```bash
pip install -r requirements.txt
# или если poetry
poetry install
```
Примените миграции базы данных:

```bash
python manage.py migrate
```
Создайте суперпользователя для админки:

```bash
python manage.py csu
```
Запустите сервер разработки:

```bash
python manage.py runserver
```
